# industrial_susbsidies_analysis
Development Economics research project analyzing the relationship between industrial subsidies and economic growth in India using econometric and statistical analysis in Microsoft Excel.
# Do Industrial Subsidies Drive Economic Growth in India?

## Overview
This development economics project examines whether industrial subsidies contribute to economic growth in India using regression analysis and economic indicators.

## Research Question
Do industrial subsidies positively influence economic growth in India?

## Methodology
- Data collection and cleaning
- Descriptive statistics
- Correlation matrix
- OLS regression analysis
- Trend visualization using Excel

## Tools Used
- Microsoft Excel
- Regression Analysis
- Data Visualization
- Econometric Concepts

## Key Findings
- Identified relationships between subsidy allocation and growth indicators
- Explored statistical significance and economic interpretation

- Econometric analysis
- Data interpretation
- Research methodology
- Policy analysis
- Presentation design
